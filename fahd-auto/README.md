# Fahd Auto website

A responsive car dealership website built with semantic HTML5, CSS3 and vanilla JavaScript.

## Run locally

Open `index.html` in a modern browser. An internet connection is needed for Google Fonts and the externally hosted vehicle photography.

## Included interactions

- Responsive mobile navigation and sticky header
- Inventory filtering by body style, make/model and budget
- Save/favourite vehicle buttons
- Vehicle enquiry buttons that prefill the contact form
- Review carousel controls
- Single-open FAQ accordion
- Client-side form validation and toast feedback

## Before publishing

- Replace sample inventory, prices, mileage, and testimonials with verified dealership data.
- Connect the contact form to a backend, CRM, or form service. It currently validates locally and does not send submissions.
- Replace sample location/contact details with the dealership's real details.
- Confirm image licensing and availability; photos currently load from Unsplash image URLs.
- Add privacy policy, terms, and any required provincial/legal dealership disclosures.
